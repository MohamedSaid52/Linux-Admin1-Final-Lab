## Phase 2: File System Structure & Permissions

* Create directories: Build the infrastructure paths at /data/dev and /data/finance.
   ### Implementation

   here i make the directory called data under / , and make two directories under data 
   mkdir /data
   mkdir /data/dev
   mkdir /data/finance

* Restrict ownership: Apply chown and chmod so only respective group members can access their directory.
   ### Implementation
 
   Here i have changed the owner user 
   chown developer-user /data/dev/
   chown accounting-user /data/finance/

   Here i have changed the owner group 
   chown :developers /data/dev/
   chown :accounting /data/finance/

   Here i applied chmod so i have give the full permission to owner user and owner group 
   chmod 771 /data/dev/
   chmod 771 /data/finance/

* Block external access: Deny all read, write, and execute permissions for unprivileged or outside users.
   ### Implementation

   Here i have deneyied other user permission and make access for owner user and owner group 
   chmod 770 /data/finance/
   chmod 770 /data/dev/

* Apply special permissions: Enable the Sticky Bit on shared folders to prevent users from deleting files owned by others.
   ### Implementation

   Here i make sticy bit so that no one can delete other users files 
   chmod +t /data/finance/
   chmod +t /data/dev/
